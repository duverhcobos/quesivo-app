# Propuestas

Aquí viven las propuestas de cambio de código antes de aplicarse, siguiendo el flujo descrito en
`AGENTS.md` (sección "0. Flujo de trabajo obligatorio: propuestas de código").

- Nombra cada propuesta como `<numero>-<descripcion>.md` (ej. `01-forgot-password-screen.md`).
- Una propuesta describe el cambio completo (archivos nuevos con código completo, archivos
  existentes solo con el fragmento Antes/Después) antes de tocar el código fuente real.
- Las propuestas aplicadas pueden conservarse aquí como historial de decisiones.
